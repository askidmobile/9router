# Google AI Studio: импорт моделей и Flex

Проверено 7 сентября 2026 года. Имя провайдера в dashboard — **Google AI Studio**.
Его технический идентификатор и префикс маршрутизации остаются `gemini`.

## Модели

Внутренний ID импортированной модели: `gemini-3.8-flash`, без `models/`.
Импорт загружает все страницы Google Models API и предлагает отдельные Flex
варианты для моделей из документированного списка поддержки.
В native Gemini API `/v1beta/models` префикс `models/` сохраняется по контракту Google.

Примеры выбора в OpenAI-совместимом клиенте:

- `gemini/gemini-3.5-flash-lite` — обычный режим, по умолчанию Standard.
- `gemini/gemini-3.5-flash-lite:flex` — Flex.

Также можно передать `"service_tier": "flex"` в запросе к обычному ID модели.
Поддерживаются Chat Completions, Responses, Claude Messages и native Gemini.
Роутер передаёт Google исходный ID модели и верхнеуровневый `serviceTier: "flex"`.
Противоречащие друг другу ID и параметры возвращают HTTP 400 до обращения к ключам.
Повторные попытки сохраняют Flex; автоматического повышения до Standard нет.
Если пользователь самостоятельно включает другие модели в fallback-комбо,
выбор этих моделей по-прежнему определяется настройками комбо.

Flex допускает долгую очередь: роутер и кнопка проверки модели ждут до 15 минут.
В клиенте и внешнем reverse proxy также нужен подходящий timeout, например 900 секунд.
Короткие таймауты обычных запросов не меняются.

## Что означает бесплатность

`Free of charge` — нулевая цена указанной операции на Free Tier в пределах квот
проекта. Колонка «за 1 млн токенов» задаёт единицу цены, а не бесплатную квоту.
Количество запросов и токенов ограничено отдельно для каждой модели и проекта;
дневная квота запросов обновляется в полночь Pacific Time.
Актуальные доступные лимиты показаны в AI Studio → Usage → Rate limits.

Free Tier зависит от модели и режима. На дату проверки у Gemini 3.8 Flash Flex
бесплатный тариф недоступен; у Gemini 3.5 Flash-Lite Flex в таблице указан
`Free of charge`. На платном проекте применяются платные ставки, включая Standard.
Переключение имени модели само по себе не меняет billing tier проекта API-ключа.
Ключи одного Google-проекта делят квоты; ключи разных проектов могут иметь разные
тарифы. Нельзя считать выбор обычной модели гарантией бесплатного запроса к платному ключу.

Flex использует менее приоритетные мощности: ориентир ожидания 1–15 минут,
возможны 503 при нехватке мощности и 429 при исчерпании квот. Общие квоты
проекта сохраняются. Для платного тарифа заявлена скидка 50% относительно Standard.
Показатели стоимости в 9Router остаются оценкой по настроенной таблице цен;
фактическую бесплатность и списания показывает Google Billing.

## Проверка подключения

Прямой контрольный запрос к Google с текущего сервера: `gemini-3.5-flash-lite`,
`serviceTier: "flex"`, лимит ответа 32 токена. Получены HTTP 200, ответ `OK.`,
`usageMetadata.serviceTier: "flex"`, 5 входных и 2 выходных токена, 779 мс.
Это подтверждает выполнение в Flex; по ответу API нельзя установить фактическую цену.
