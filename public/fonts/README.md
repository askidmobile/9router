# Material Symbols Outlined

Self-hosted Google Material Symbols v377, downloaded from the official Google Fonts API on 2026-10-12. All glyphs are retained. Axes match the application CSS: opsz=24, wght=400, GRAD=0; FILL remains variable from 0 to 1.

CSS source: https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0..1,0

Use a modern Chromium User-Agent to obtain WOFF2. The resulting font is 294212 bytes, replacing the installed package's 3.8 MB font without adding a runtime dependency. Apache 2.0 license is included alongside it.
